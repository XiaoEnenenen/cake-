# 套餐（方案 A）录入指南 —— 零开发，店主自己就能上

> 适用：R-02「可以发布套餐吗？」（店主 2026-10-12 微信）。
> 阶段 11 采用**方案 A**：**套餐 = 一个普通商品**，不新增"套餐对象"。
> 好处是**今天就能卖**：店主端现有「商品管理 → 新增商品」就能录，不用改代码、不用发版。
> 代价是：套餐里的子商品**不能单独统计销量/库存**（本店本来就没有库存概念），
> 订单里是"套餐 × 1"一行，店主按详情文字备料。

## 一、什么时候用方案 A（够用）

| 场景 | 方案 A 是否够 |
|---|---|
| 生日套装（主蛋糕 + 纸杯蛋糕 6 只） | ✅ 够 |
| 下午茶套餐（切块 × 4 + 饮品 × 2） | ✅ 够 |
| 按档位卖（基础套装 / 升级套装） | ✅ 够（用规格组做档位） |
| 需要"套餐内子商品可单独换、单独退" | ❌ 需要方案 B（真套餐对象，另做 2–3 天） |
| 需要按子商品分别统计销量/成本 | ❌ 需要方案 B |

方案 B 的评估见 `实施步骤清单.md` 阶段 11 第 9 步；**等她确认要，再动代码**。

## 二、录一个套餐（店主端，5 分钟）

入口：小程序 →「我的」→「店主中心」→「商品管理」→ 右下角「＋ 新增商品」。

| 字段 | 怎么填 | 例子 |
|---|---|---|
| **名称** | 一眼能看出是套餐、含什么 | `生日套装｜主蛋糕 + 纸杯蛋糕 6 只` |
| **分类** | 放顾客最可能找的分类（一般是「生日蛋糕」） | `生日蛋糕` |
| **价格** | 填**最低档**的套餐价（档位加价在规格组里设） | `168` |
| **单位** | `套`（不要用"个"，顾客会以为是单个蛋糕） | `套` |
| **规格组** | 组名写 `档位`，选项写清每档含什么；加价填与最低档的差价 | 组名「档位」；选项 `基础套装（6寸+6只）` 加价 `0`、`升级套装（8寸+8只）` 加价 `50` |
| **详情** | 用文字写清：**包含什么 / 几人份 / 提前几小时订 / 能不能换口味**（详情页会按段落显示） | 见下方模板 |
| **图片** | 至少 1 张（建议拍"摆在一起"的合影，顾客才知道是一套） | — |
| **上下架** | 录完打开「上架」 | ✅ |
| **排序** | 数字越小越靠前（想放前面就填小一点） | `5` |

### 详情文案模板（直接抄改）

```text
生日套装｜主蛋糕 + 纸杯蛋糕 6 只
包含：6 寸生日蛋糕 1 个（口味可选：草莓 / 巧克力 / 奥利奥）
　　　纸杯蛋糕 6 只（奶油 + 新鲜水果装饰）
适合：4~6 人
预订：请至少提前 3 小时下单；需要写生日牌请在备注里写清文字
其他：蛋糕需冷藏，建议取货后 2 小时内食用
```

> ⚠️ 三个容易踩的点：
> 1. **规格组 id / 选项 id 一旦有顾客下过单就不要改名**（店主端编辑页有提示）——
>    购物车与订单快照靠它算价，改名等于换规格；
> 2. 价格与档位加价必须是数字，加价不能为负；
> 3. 套餐也能用优惠券：券只抵**商品金额**（不含打包费、运费），满减门槛按套餐价判断。

## 三、录完怎么验（2 分钟）

1. 用**另一个微信号**打开小程序 → 点单页能看到套餐 → 点进去选档位 → 加购；
2. 结算页显示套餐价 + 档位差价的正确金额；
3. 下单后到订单详情/店主端订单看：
   - 金额对不对；
   - 商品行有没有档位说明（`基础套装（6寸+6只）`）——**店主备料就靠这一行**；
4. 若同时建了优惠券：结算页选券后实付应再减掉优惠金额（`amountReal = 套餐价 - 优惠 + 打包费 + 运费`）。

> 这套链路已有机械测试守着：`tests/test-coupon.js` 第 8 节会真的用店主商品接口录入一个套装
> （168 元 / 升级档 +50），再走一遍顾客下单，断言 168 / 218 与订单快照正确 ——
> 也就是说"方案 A 能下单"不是口头承诺，是每次 `npm test` 都会重新验证的事实。

## 四、等店主给的资料（给了就照上面录入）

| # | 需要她确认 | 为什么 |
|---|---|---|
| 1 | 套餐包含哪些商品、各几个 | 写进详情 |
| 2 | 几个档位、每档价格 | 最低档填商品价格，其余用规格组加价 |
| 3 | 几人份 / 适合场景 | 详情第一段就写这个，顾客最关心 |
| 4 | 提前几小时订、能不能换口味 | 提前时间影响下单校验（现有规则：含蛋糕提前 3 小时） |
| 5 | 要不要"套餐图" | 拍一张合影；没有就先用主蛋糕图 |
